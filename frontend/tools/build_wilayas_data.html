Build NASA POWER data for the 58 wilayas

Run once on a computer with internet. It downloads 30 Sep–Aug seasons (1995-96 to 2024-25) of daily NASA POWER data for each wilaya seat, runs the same cleaning and indicator pipeline as the game (nasa_direct.js), adds SoilGrids soil and Copernicus slope when those services answer, and gives you wilayas_data.js. Put that file in data/ (replace the empty one). Already-built wilayas are kept on this computer, so you can stop and resume.
